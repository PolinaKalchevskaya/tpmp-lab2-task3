# tpmp-lab2-task3 - Cinema Management System

## Overview
Программа для управления данными о фильмах с использованием структур языка C.
Реализует структуру CINEMA с функциями для анализа данных о фильмах.

## Author

## Usage
Запуск программы:
```bash
make
make run
```

Проект разработан в соответствии с моделью КИС (Клиент-Интерфейс-Сервер).
